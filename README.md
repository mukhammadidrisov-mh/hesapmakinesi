# Hesap Makinesi (Calculator App)

Bu proje, modern bir arayüze ve çeşitli gelişmiş özelliklere sahip bir Android hesap makinesi uygulamasıdır.

## 🚀 Özellikler

- **Temel İşlemler:** Toplama, çıkarma, çarpma ve bölme.
- **Yüzde Hesaplama:** Gelişmiş yüzde hesaplama mantığı.
- **Anlık Sonuç:** Siz yazarken sonucu alt satırda anlık olarak görebilme.
- **İşlem Geçmişi:** Yapılan tüm hesaplamaları geçmiş listesinde görebilme ve yönetme.
- **Sesle Hesaplama (Speech-to-Calculate):** Sesli komutlar ile matematiksel işlemleri gerçekleştirebilme.
- **Gece Modu Desteği:** Göz yorgunluğunu azaltmak için karanlık tema seçeneği.
- **Özelleştirilebilir Tema:** Arka plan renklerini ve buton stillerini değiştirme imkanı.
- **Modern Animasyonlar:** Akıcı geçişler ve etkileşimli UI elemanları.
- **Reklam Entegrasyonu:** AdMob geçiş reklamları (Interstitial Ads) desteği.

## 🛠️ Kullanılan Teknolojiler

- **Dil:** Kotlin
- **Mimari:** Modern Android Geliştirme pratikleri
- **UI:** XML Layouts & Material Design
- **Kütüphaneler:**
    - Jetpack Lifecycle (ViewModel, Coroutines)
    - Navigation Component
    - Google Play Services Ads
    - SharedPreferences (Veri saklama için)
    - Speech Recognizer API

## 📱 Kurulum

1. Bu depoyu klonlayın:
   ```bash
   git clone https://github.com/mukhammadidrisov-mh/hesapmakinesi.git
   ```
2. Android Studio ile projeyi açın.
3. Gerekli bağımlılıkların yüklenmesi için Gradle senkronizasyonunu bekleyin.
4. Bir emülatör veya gerçek bir cihaz üzerinde çalıştırın.
